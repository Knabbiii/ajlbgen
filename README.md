# AJLB Papi Stats Generator

A simple web tool to generate leaderboard YAML config for the **AJLB** plugin using **PlaceholderAPI** statistics placeholders.

## Features

- All papi `%statistic_...%` placeholders in one searchable list
- Supports parameterised stats (`mine_block`, `use_item`, `break_item`, `craft_item`, `kill_entity`, `entity_killed_by`) with a searchable material/mob picker (MC 1.21)
- Configurable title, category label, time period (weekly/daily/monthly/alltime) and top N entries
- Outputs ready-to-paste YAML in the standard AJLB hologram format
- Dark mode, single HTML file, no dependencies

## Usage

Open [the generator](https://knabbiii.github.io/AJLBGEN), fill in the fields and click **Generate**.
